[[A problem in a game for children||Un problème dans un jeu pour enfants]]

[[If something in a game of the catalogue seems unsuitable or unsafe for children, write to us with the game's name and what you saw. It is our first priority: the game is taken offline while we check.||Si quelque chose dans un jeu du catalogue vous semble inadapté ou risqué pour des enfants, écrivez-nous avec le nom du jeu et ce que vous avez vu. C'est notre première priorité : le jeu est retiré le temps de vérifier.]]

[[A game that uses the name Ludea||Un jeu qui utilise le nom Ludea]]

[[Games made with the Ludea engine may say « made with Ludea », even when Ludea does not publish them. Only the games of the catalogue have been reviewed by Ludea. If a game outside the catalogue uses the name Ludea and seems harmful — to children above all — write to us with its address: we ask its creator to remove the mention, and report it to its host when needed.||Les jeux faits avec le moteur Ludea peuvent indiquer « fait avec Ludea », même quand Ludea ne les publie pas. Seuls les jeux du catalogue ont été vérifiés par Ludea. Si un jeu hors catalogue utilise le nom Ludea et vous semble nuisible — pour des enfants avant tout — écrivez-nous avec son adresse : nous demandons à son créateur de retirer la mention, et le signalons à son hébergeur si besoin.]]

[[You made a game||Vous avez créé un jeu]]

[[From your game's Claude Code session: /idea sends an idea or a problem to the engine team, /publish asks for your game to join the catalogue (or sends an update). To remove your game from the catalogue, just write to us.||Depuis la session Claude Code de votre jeu : /idea envoie une idée ou un problème à l'équipe du moteur, /publish demande l'entrée de votre jeu au catalogue (ou envoie une mise à jour). Pour retirer votre jeu du catalogue, écrivez-nous simplement.]]
